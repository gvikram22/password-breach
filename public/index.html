How does it work?

Your browser sends the password securely to this demo backend. The backend computes its SHA-1 hash, sends only the first five characters to Have I Been Pwned, and compares the returned hash suffix locally. MongoDB stores only an anonymous check count—not your password or its hash.

Frequently asked questions

Does this save my password?

No. Passwords and hashes are not saved in MongoDB or application logs.

What does an exposed result mean?

The password appeared in known breach datasets. Stop using it and replace it anywhere it was reused.

Does “not found” mean completely safe?

No. It only means no match was found in the dataset checked.
